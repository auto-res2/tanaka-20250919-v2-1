# Paper Outline
The core methodology involves an iterative LLM-driven objective discovery pipeline. An LLM (GPT-4) is iteratively prompted to propose new preference optimization loss functions in code (PyTorch). The process starts with an initial context including established loss functions and their performance. For each proposed function, unit tests are run for validity, and then an LLM is fine-tuned using the proposed objective. The resulting model's performance on a predefined downstream validation task (MT-Bench score) is evaluated and fed back to the LLM as an in-context example. The LLM refines its proposals based on this feedback, exploring variations and new formulations. The discovered DiscoPOP (Log Ratio Modulated Loss) is a dynamically weighted sum of the logistic loss (used in DPO) and the exponential loss, where the weights are determined by a sigmoid calculation of the difference in log-ratios (ρ) with a temperature parameter.
